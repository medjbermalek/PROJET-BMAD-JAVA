# Revue éditoriale de l'addendum

## Lecture et modèle

L'addendum aide les lecteurs produit et techniques à consulter les choix issus du brief, les hypothèses techniques et les références UX. Modèle retenu : Référence / base de données. Lecteur humain; style de référence : Microsoft Writing Style Guide.

## Structure

Préserver les trois rubriques et leur ordre : choix techniques, hypothèses à confirmer, recherche UX. Elles ont des fonctions distinctes et permettent le repérage rapide. Réduction estimée : 0 mot sur 270.

## Prose

| Texte original | Proposition | Motif |
|---|---|---|
| « Le brief laisse le choix entre mode mémoire et mode fichier ouvert. » | « Le brief ne tranche pas entre le mode mémoire et le mode fichier. » | Clarifie que le choix reste indéterminé, sans laisser entendre que le fichier est « ouvert ». Correction appliquée. |

## Choix de style à préserver

Structure en listes, termes techniques, incertitudes explicites et liens vers les sources.
